## 需要专用 FSM/对象适配器的效果

以下效果不能只靠统一数值补丁可靠完成，建议按护符拆成独立适配器：

- 巴德尔之壳层数、破壳和修复
- 发光子宫、编织者、格林之子等召唤物数量/攻速/伤害
- 防御者纹章、蘑菇孢子、吸虫之巢的粒子和伤害判定
- 荆棘之怒额外判定
- 蜕变挽歌额外剑气
- 梦之盾的数量、大小、旋转周期和命中回魂
- 乌恩之形、蜂巢之血、深度聚集等状态机联动
- 额外冲刺、额外跳跃、缓降
- 无忧旋律多重概率判定
- 骨钉技精确释放、法术化和无敌帧
- 水晶冲刺伤害、冷却和硬着陆
- 生命血 UI 与乔尼生命换算

这些效果的设计文本没有丢失，全部保存在 `CharmDatabase.Generated.cs` 和 `Design/charms_source.json` 中。

## 推荐扩展方式

1. 在独立 DLL 中引用 `CharmsEvolve.dll`。
2. 使用 `CharmsEvolveApi.IsEquipped("X-05")` 判断复制护符。
3. 使用 Harmony 或 PlayMaker FSM 编辑完成该效果。
4. 在 `EquipmentChanged` 事件中重新应用/卸载效果。
5. 使用 `RegisterTexture` 为该护符提供新贴图。
